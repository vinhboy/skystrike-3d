# Skystrike 3D

Browser fighter-pilot game with procedural Web Audio, three switchable weapons, wingmen and assisted runway landing.

Open the GitHub Pages site and click **START MISSION**. Use WASD/arrows to fly, Space to fire, 1/2/3 to switch weapons, Shift for afterburner, and R to restart. The sound button toggles audio.

## Source and hosting

`source/skystrike_3d.html` preserves the downloaded game. `index.html` changes only the Three.js import to the bundled `vendor/three.module.js` (0.160.0). Its license is retained in `vendor/THREE-LICENSE.txt`. All game scenery and sound are generated in code; no separate media assets are required.
